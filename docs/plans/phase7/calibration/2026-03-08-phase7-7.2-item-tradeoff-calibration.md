# Phase 7.2 - Item Tradeoff Calibration

## 1. 目的

把 `itemTradeoff` 从“散落在 compare / merchant / simulator 的隐式常量”收口成单一 calibration asset。

当前 asset：

- `id`: `phase7-7.2-item-tradeoff-v1`
- 代码入口：
  - `packages/core/src/itemTradeoffCalibration.ts`
  - `packages/core/src/itemTradeoff.ts`

## 2. 校准边界

本资产只负责：

1. `offense / defense / utility` 维度权重
2. slot identity 加权
3. merchant compare 的高价值门槛
4. representative sample 的冻结

本资产不负责：

1. 运行时掉落概率
2. 装备数值生成
3. 美术/音频表达

## 4. Merchant Compare 门槛

当前统一门槛：

- `minPowerDelta = 10`
- `minPositiveSummaryCount = 2`

解释：

1. `powerDelta` 过滤低价值 sidegrade
2. `positiveSummaryCount` 保证商店 compare 只在明显升级节点打断流程

## 5. Representative Samples

### 5.1 weapon-major-upgrade

- 目标：`rare weapon` 明显升级时必须被 compare / merchant / simulator 同时视为高价值
- 预期：`powerDelta > 10`

### 5.2 boots-tradeoff-mobility

- 目标：带负移速或负生存的 boots sidegrade 仍能体现 trade-off，而不是被简单打成“更强”
- 预期：summary 至少同时出现 `up` 与 `down`

### 5.3 low-value-merchant-sidegrade

- 目标：common / weak magic merchant purchase 不应触发 compare prompt
- 预期：不满足 `minPowerDelta` 或 `minPositiveSummaryCount`

## 6. 治理规则

1. 任何权重或 merchant 门槛调整，都必须同步更新本文件。
2. 调整前必须先说明它影响的是：
   - compare
   - merchant gating
   - simulator equip decision
3. 不允许只改代码不更新 representative sample 说明。
