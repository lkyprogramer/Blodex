# Phase 7.2 - Threshold Governance

## 1. 目的

把 `policy threshold` 与 `calibration override` 明确拆开，避免继续把当前样本值直接编码进 report。

代码入口：

- `apps/game-client/src/systems/balance/BalanceThresholdGovernance.ts`
- `apps/game-client/src/systems/balance/Phase6EvidenceRegistry.ts`
- `apps/game-client/src/systems/balance/RealBalanceReport.ts`

## 2. 治理结构

### 2.1 global policy

唯一全局 policy：

- `id`: `phase6-default-drift-thresholds`
- `baselineCommit`: `19574b7`

默认门槛：

| 指标 | policy |
|---|---:|
| `clearRate` | `0.62` |
| `avgFloorReached` | `1.75` |
| `rareShare` | `0.09` |
| `avgRunDurationMs` | `150000` |

### 2.2 scenario override

当前允许的 override：

| scenario | id | diffClass | sourceSampleSize |
|---|---|---|---:|
| `hard-average` | `phase6-6.5-hard-average-v2` | `sampling_mismatch` | `18` |
| `nightmare-optimal` | `phase6-6.5-nightmare-optimal-v1` | `model_incomplete` | `18` |

## 3. diff classification 规则

允许值：

1. `model_incomplete`
2. `sampling_mismatch`
3. `runtime_bug`
4. `content_drift`

治理规则：

1. `runtime_bug` 不允许作为 override 进入 registry。
2. `override` 必须带：
   - `baselineCommit`
   - `evidenceArtifactId`
   - `sourceSampleSize`
   - `rationale`
3. `policy` 与 `override` 必须各自只有单一事实源，不允许 pack/report 再本地硬编码第二套门槛。

## 4. 审计结果

当前审计要求：

1. `global_default` 数量必须为 `1`
2. 每个 override 必须有 `scenarioName`
3. 每个 override 必须有 `diffClass`
4. 每个 override 必须有 `sourceSampleSize > 0`
5. 每个 override 必须指向存在的 evidence artifact

## 5. 维护要求

1. 任何新增 override，都必须先补本文件。
2. 如果 sample size 改变，应显式新增或替换 override 记录，不允许静默复用旧记录。
3. `Phase6EvidencePack` 只能消费 registry 结果，不能再保留本地 `difficulty -> scenario` 或 threshold 常量。
